# QA Checklist

## A. Product truth
- Correct model/SKU.
- Correct color/variant.
- Correct proportions.
- Correct control count and placement.
- Correct ports/openings.
- Correct light-emitting area.
- Correct output/mist location.
- Correct included items and quantity.
- Correct packaging.
- No invented claim.

## B. Visual continuity
- Same material finish across frames.
- No logo drift.
- No label crawling.
- No shape morphing.
- No disappearing parts.
- No duplicated accessories.
- No unexplained variant change.

## C. Motion
- Natural acceleration/deceleration.
- No camera jitter.
- No temporal flicker.
- No hand/object penetration.
- No physically impossible movement.
- Loop seam is acceptable where required.

## D. Brand
- Lighting fits brand.
- Background/props fit brand.
- Typography follows brand rules.
- Color grade is consistent.
- Reference influence is transformed, not copied.

## E. Ecommerce
- Product is legible at intended screen size.
- Main action is understandable muted.
- Mobile crop retains product/action.
- Homepage hero leaves safe space for HTML copy/CTA.
- PDP feature loop demonstrates one clear benefit.
- Poster frame is clean.

## F. Technical
- Expected duration.
- Expected aspect ratio.
- Expected resolution.
- Audio present only when intended.
- Encoded file opens successfully.
- File size measured.
- No accidental alpha/background issue.

## Status

### PASS
Ready for edit/export.

### RETRY
Generation issue can likely be fixed.

### BLOCKED
Missing source, renderer capability, or required asset.

### UNVERIFIED
Cannot validate against source-of-truth.

Record reasons. Never mark PASS solely because the clip "looks good."
