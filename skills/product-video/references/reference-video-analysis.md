# Reference Video Analysis

Reference videos are for analysis, not replication.

## Metadata

Record:
- filename;
- duration;
- frame size;
- aspect ratio;
- frame rate;
- orientation;
- approximate number of shots.

## Shot-by-shot table

For each shot:
- timestamp in/out;
- duration;
- shot purpose;
- framing;
- lens impression;
- camera movement;
- product movement;
- background;
- lighting;
- transition;
- typography;
- sound;
- information conveyed;
- why it works;
- whether it fits the target brand.

## Transfer framework

### TAKE
General principles safe to reuse, such as:
- a slow edge-light reveal;
- macro material inspection;
- product-to-lifestyle match cut;
- function-before-copy hierarchy;
- hero loop ending close to opening state.

### ADAPT
Useful but must change for the target brand/product:
- color palette;
- studio architecture;
- typography;
- pacing;
- prop styling;
- amount of CGI.

### AVOID
Do not reproduce:
- the same branded staging;
- a distinctive shot sequence beat-for-beat;
- exact typography motion;
- competitor product geometry;
- competitor logos/packaging;
- music or audio;
- copied on-screen copy.

## Synthesis

After individual analyses, create a concise creative formula, for example:

`Brand mood from Reference A + camera discipline from Reference B + function visualization logic from Reference C + target brand's own visual system.`

Do not combine every reference indiscriminately.
